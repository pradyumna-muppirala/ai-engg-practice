# PythonLang-Practice

A collection of fundamental Python programming exercises covering data types, control structures, functions, and algorithms for Claude Code.

## Operations Covered

| Operation | Description | Python Signature |
|-----------|-------------|------------------|
| `add` | Add two numbers | `add(x, y)` |
| `subtract` | Subtract second number from first | `subtract(x, y)` |
| `multiply` | Multiply two numbers | `multiply(x, y)` |
| `divide` | Divide first number by second; handles division by zero | `divide(x, y)` |
| `factorial` | Compute factorial using iterative approach | Calculated in loop |

## Core Programming Concepts Demonstrated

### Data Types
- **Integers and Floats**: Variables like `age=20`, `height=5.5`
- **Strings**: String concatenation and formatting
- **Lists and Tuples**: Creation and manipulation
- **Dictionaries**: Key-value storage
- **Booleans**: True/False values

### Control Structures
- **Conditional Statements**: if/elif/else blocks with nested conditions
- **For Loops**: Iterating over lists and ranges
- **While Loops**: Basic while loops, infinite loops with break, continue statements
- **Loop Control**: Using break and continue statements

### Functions
- **Basic Arithmetic Functions**: add, subtract, multiply, divide
- **Menu-Driven Calculator**: Interactive calculator with user input
- **Factorial Calculation**: Iterative factorial computation
- **Random Number Generation**: Using random module

### Algorithms
- **Prime Number Check**: Algorithm to determine if a number is prime
- **Maximum in List**: Finding the maximum value in a list
- **Square Root Calculation**: Using math.sqrt for square roots

```

```


### Learning Exercises

The file is organized as progressive exercises:
- **Exercise 1**: Basic data types and variables
- **Exercise 2**: More data type practice and string operations
- **Exercise 3**: Conditional statements and loops
- **Exercise 4**: Menu-driven calculator
